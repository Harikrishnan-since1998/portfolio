POWER ELECTRONICS / DRIVES / CONTROL

Discrete-Time Plant Modeling for Efficient Validation of Control Systems

Control strategies are often validated using MATLAB/PLECS plant models whose accuracy depends on the numerical solver and simulation step size. This project presents an alternative approach in which the PMSM plant is explicitly discretized and executed at a sub-microsecond time step, while the control algorithm operates at its intended sampling period (100 uS). A comparative study with conventional solver-based simulation is presented to evaluate the accuracy and effectiveness of the proposed approach.

SOFTWARE / EMBEDDED SYSTEMS

QSPICE C++ to C2000 C Code Converter

QSPICE allows custom C++ code to be incorporated into circuit simulations, but the simulation-oriented code often requires significant restructuring before it can be deployed on TI C2000 DSPs. This project presents a lightweight software tool that converts QSPICE C++ code into organized .c and .h files suitable for C2000-based embedded implementation, reducing manual code restructuring and accelerating the transition from simulation to real-time control. For access to the .exe file, please contact me at shhm.1965@gmail.com.

PCB DESIGN

Basic Half bridge circuit featuring IRF840 Mosfet and IR2112 bootstrap Gate Driver

A compact half-bridge power stage built around the IR2112 bootstrap gate driver featuring IRF840. Originally designed for a synchronous buck converter with provisions to connect inductors externally, the circuit can also be configured as an independent half-bridge. The board includes provisions for voltage sensing and ACS712-based current sensing, making it suitable for rapid prototyping and testing of power-electronic converter topologies.

PCB DESIGN

Signal Conditioning Board for TMS320F28379D

C2000Ware-based DSPs are widely used in power electronics research labs, but interfacing the DSP with power converters and sensor boards often involves dozens of jumper wires, making prototyping cumbersome and fault diagnosis difficult. To address this, we developed a dedicated PCB extension board for the TMS320F28379D, featuring integrated signal-conditioning stages, including level shifters, filters, and anti-aliasing filters, along with a structured pin arrangement for cleaner and faster prototyping. Watch the video to learn more about the design and its features.

DRIVES / CONTROL

Sensor Calibration

In this project, an ACS772 current sensor with an external gain stage was calibrated against a reference current measurement using experimental data and linear regression. The calibration code automatically determines the sensor gain and offset, evaluates their variation across data segments, and compares the calibrated output with the reference measurement. The results highlight the importance of experimentally validating sensor characteristics rather than relying solely on nominal datasheet values.
